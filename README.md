기타

마이 페이지 프로필 수정은 정규식만 통과하면 가능

시연 모드에서 선호 지점은 일산, 광교로 고정 ( 실제로는 회원가입 할때 고른 선호 지점이 DB에 저장)

시연 모드에서 마이 페이지 선호 지점 선택은 일산, 광교로 고정( 실제로는 고를때 선호 지점이 실시간으로 DB에 저장)

시연 모드에서 아쿠아플라넷몰의 헤더 지점 필터는 그래서 일산,광교로 시작. (실제로는 유저가 고른 선호지점에 맞춰서 옵션이 활성화됨)

결제 페이지에서 할인이 되는 항목이 있고, 아닌 항목이 있음. 거기에서 또 할인이 되는 옵션이 있고 아닌 옵션이 있음.

시연 모드에서 아쿠아플라넷몰에서 최종 결제까지 가능, 다만 저장은 안됨. (실제로는 구매 내역이 DB에 저장됨)

시연 모드에서 내 티켓 보기는 화면상에 보이는 것으로 정해져 있음. (실제로는 유저의 구매 내역중 orderStatus속성 값이 '사용가능'인 티켓을 불러옴)

시연 모드에서 내 구매 내역 보기는 화면상에 보이는 것으로 정해져 있음 (실제로는 유저의 모든 구매 내역을 불러옴. 다만 사용완료는 미구현)

시연 모드에서 환불하기는 성공 메시지를 띄우되 화면상 변하는 것은 없음 
(실제로는 환불한 티켓의 OrderStatus가 '환불완료'가 되고 왼쪽 구역의 티켓 리스트가 업데이트 됨)
